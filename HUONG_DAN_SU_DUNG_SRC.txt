2. CHẠY / TẮT SERVER
--------------------------------------------------------------------------
Chạy (khuyên dùng):
  1. Vào VPS bằng Windows App / Remote Desktop.
  2. Mở NetBeans, chọn project SRC.
  3. Sau mỗi lần sửa code: chuột phải project -> Clean and Build.
  4. Bấm Run. Server khởi động + cửa sổ Panel quản lý tự hiện.
  5. Đợi dòng "Server initialized and listening on port 14445".

Tắt:
  - Nên bảo trì trước (Panel -> nút "Bảo Trì (30s)") để lưu dữ liệu người chơi,
    sau đó bấm Stop trong NetBeans.

Lưu ý:
  - Chạy server ở chế độ ẩn (dịch vụ, SSH) thì panel KHÔNG hiện được.
  - Mỗi lần chỉ chạy 1 server, chạy 2 cái sẽ lỗi trùng cổng 14445.
  - 20 bot người chơi xuất hiện khoảng 15 giây sau khi server khởi động.

3. KẾT NỐI TỪ MÁY CÁ NHÂN
--------------------------------------------------------------------------
MySQL chỉ mở trong VPS (127.0.0.1), muốn xem DB từ máy mình thì mở đường hầm SSH.
Trên Mac, mở Terminal và để nguyên cửa sổ này:

    ssh -N -L 8080:127.0.0.1:80 -L 3307:127.0.0.1:3306 dataz

  - Chrome:  http://localhost:8080/phpmyadmin   (đăng nhập user DB)
  - Navicat / DBeaver / TablePlus:  host 127.0.0.1, port 3307, DB nro_merge

Sửa code từ xa: VS Code + Remote-SSH tới host "dataz",
mở thư mục C:\Users\Administrator\Desktop\SRC.

4. FILE CẤU HÌNH  Config.properties  (trong thư mục SRC)
--------------------------------------------------------------------------
Sửa xong phải khởi động lại server (trừ pet.vip.enabled - đọc mỗi lần dùng).

  server.ip ............. IP gửi cho client (160.30.136.55)
  server.port ........... cổng game (14445)
  server.maxperip ....... số tài khoản tối đa trên 1 IP
  server.maxplayer ...... số người chơi tối đa
  server.expserver ...... nhân kinh nghiệm toàn server
  server.waitlogin ...... giây chờ giữa 2 lần đăng nhập

  database.name ......... DB đang dùng (nro_merge)
  database.user / pass .. tài khoản DB
  database.min / max .... số kết nối DB (2 / 12). ĐỪNG đặt max = 1, server sẽ treo.

  napthe.partner_id / partner_key .. tài khoản cổng nạp thẻ (của bạn, đang để trống)

  pariry.enabled ........ bật/tắt tính năng Pariry
  bot.new.enabled ....... bot kiểu AWN cũ (đang tắt, nên để tắt)
  bot.player.count ...... số bot giống người chơi (20; 0 = tắt)
  pet.vip.enabled ....... đệ tử VIP (Mabư/Uub/KidBeer/Jiren): false = tạm khóa
  minigame.taixiu_chanle.enabled .. Tài xỉu (Mèo Đỏ Đen) + Chẵn lẻ (Vua Cờ Bạc):
                          false = tắt (mặc định), true = mở. Đọc mỗi lần dùng.
  event.vulan / valentine / blackfriday / day2010 .. bật/tắt sự kiện

5. PANEL QUẢN LÝ (ADMIN)
--------------------------------------------------------------------------
Tự mở khi Run trong NetBeans. Các điểm cần biết:

  - Bảo Trì (30s): đếm ngược 30 giây rồi bảo trì (lưu dữ liệu, đóng server).
    Hẹn giờ bảo trì cũng đếm ngược 30 giây khi tới giờ.
  - Triệu hồi Boss: danh sách đủ 144 boss, có cột "Vị trí (Map - Khu)".
    Bấm "Làm mới vị trí" để quét lại. Nhấp đúp hoặc nút "TRIỆU HỒI NGAY".
  - Quản lý Boss: sửa dữ liệu boss trong BossesData (193 bộ).
  - Người chơi: sửa nhân vật.
      * PHẢI cho nhân vật thoát game (hoặc kick) rồi mới lưu, panel sẽ chặn
        nếu nhân vật đang online (vì server sẽ ghi đè khi họ thoát).
      * Đồ mặc được tự xếp đúng ô theo loại item.
  - Buff Item trong panel: CHƯA HOẠT ĐỘNG (server không nhận lệnh).
    Muốn buff item hãy dùng menu admin trong game.
  - Giftcode, Shop, Item, Map, Part, Radar, Danh hiệu, Drop, Sự kiện, Nạp:
    sửa trực tiếp DB. Sửa xong thường phải khởi động lại server.
  - AntiDDoS cần cài Npcap mới chạy được (chưa cài).

7. CÁC THAY ĐỔI GAMEPLAY ĐÃ LÀM

Đệ tử:

9. GIỚI HẠN CỦA CLIENT  (sửa vượt là client lỗi, trắng hành trang, quay mãi)
--------------------------------------------------------------------------
  - Option item (item_option_template): tối đa 255 dòng, id 0 - 254.
  - Mob template và NPC template: id tối đa 127 (đang dùng gần hết).
  - Map: tối đa 255 map (đang có 250, id 0 - 249).
  - Danh sách item gửi client gói trong 2 gói ~65KB. Server tự cắt bớt mô tả
    item nếu thiếu chỗ (mô tả item AWN id >= 2000 không gửi cho client).
  - Sau khi thêm/sửa item, option, map, part: tăng phiên bản trong
    src\nro\models\data\DataGame.java (vsItem, vsData, vsMap) rồi build lại,
    để client tự tải lại dữ liệu. Hiện tại: vsData=11, vsMap=3, vsItem=11.
  - Hình nhân vật/boss (part) lấy từ bảng part trong DB, server tạo lại file
    data\update_data\part mỗi lần khởi động. Sửa part xong phải tăng vsData.
    77 part trống (1761, 1762, 1869-1943) đã lấp bằng dữ liệu AWN (Gomah...).
  - Icon item nằm ở data\icon\x1..x4\<icon_id>.png. Thiếu file thì client
    hiện icon thay thế.

10. LOG VÀ CÁCH XEM LỖI
--------------------------------------------------------------------------
  - Log server:  C:\Users\Administrator\Desktop\SRC\logs\server-YYYYMMDD.log
                 (ghi y hệt cửa sổ Output của NetBeans)

      ~/Library/Containers/com.franke.Whisky/Bottles/<bottle>/drive_c/users/
      <tên>/AppData/LocalLow/DefaultCompany/DragonBoy/Player.log
  - Lỗi hay gặp:
      * "Access denied for user ..."  -> sai user/pass DB hoặc my.ini có
        skip-name-resolve.  Kiểm tra C:\xampp\mysql\bin\my.ini.
      * Client quay mãi / hành trang trống -> dữ liệu gửi client vượt giới hạn
        (mục 9) hoặc chưa tăng phiên bản dữ liệu.
      * "Port 14445 already in use" -> đang có server khác chạy.
